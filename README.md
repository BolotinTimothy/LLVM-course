#### Первое задание

Мною был реализован алгоритм [diffusion-limited aggregation](https://en.wikipedia.org/wiki/Diffusion-limited_aggregation)

Изначально в центре есть неподвижная частица и другие появляются в растущем квадрате вокруг нее, при касании подвижной частицей неподвижной она останавливается и таким образом фигура растет. 

Нажатием на точку можно сделать там новый центр фигуры.

Стандартный размер окна 512x512, можно изменить в sim.h

Сгенерированный оптимизированный LLVM IR файл - app-opt.ll
    
#### Второе задание 

Мною был реализован необходимый трассер использования IR инструкций, также он раскрывает один уровень использования
`phi` как операнда, а также анализатор логов `analyzer.py`

Логи пишутся в `log.txt`, в нем сейчас есть первые 400 строк вывода

- `pass.cpp` - реализованный Pass
- `app-opt-with-usage.ll` - LLVM IR файл для `app.c` с использованием плагина `pass.cpp` 
- `stats-i.csv` - файлы с собранными статистиками с фиксированной длинной окна - `i`
- `log.c` - файл с логикой вывода 

### Запуск
- компиляция программы
```bash
make app
```

- запуск программы 
```bash
make run 
```

- генерация оптимизированного LLVM IR файла  
```bash
make app-opt.ll
```
- компиляция pass.cpp в shared object
```bash
make libPass.so
```
- компиляция программы с трассировкой
```bash
make app-with-usage
```
- генерация LLVM IR с встроенной трассировкой 
```bash
make app-opt-with-usage.ll 
```

- запуск программы с трассировкой
  (трасса записывается в `log.txt`)

```bash
make run-with-usage
```

- запуск анализатора
```bash
make analyze len=(длинна окна)
```
