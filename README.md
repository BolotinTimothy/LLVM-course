### Описание
Это первое дз по курсу LLVM 2026. Авто Болотин Тимофей Иванович ИТМО.

Мною был реализован алгоритм [diffusion-limited aggregation](https://en.wikipedia.org/wiki/Diffusion-limited_aggregation)

Изначально в центре есть неподвижная частица и другие появляются в растущем квадрате вокруг нее, при касании подвижной частицой непожвижной она останавливается и таким образом фигура растет. 

Нажатием на точку можно сделать там новый центр фигуры.

Стандартный размер окна 512x512, можно изменить в sim.h

Сгенерированный оптимизированный LLVM IR файл - app-opt.ll

### Запуск
#### для запуска программы
```
make run
```

 или 
```
make app
./app
```

#### для генерации LLVM IR
```
make ir
```
